### 食安管理系统 - 校园端

```
总览
    查看日常管理、系统公告、报警趋势、库存提醒。

食堂管理
    菜品库
        查看菜品库数据，新增、编辑、删除菜品库数据。
    陪餐对象
        查看陪餐对象数据，新增、编辑、删除陪餐对象数据。
    本周食谱
        查看本周食谱数据，新增、编辑本周食谱数据。
    食谱库
        查看食谱库数据。

食材库存
    库存管理
        查看食材库存数据，查看批次数据，批量盘点、批量出库、扫码出库。
    入库台账
        查看入库台账数据。
    出库台账
        查看出库台账数据。
    盘点记录
        查看盘点记录数据。

统计报表
    入库统计报表
        查看日期汇总、食材汇总、供应商汇总数据。
    出库统计报表
        查看日期汇总、食材汇总、供应商汇总数据。
    采购价格偏差
        查看采购价格偏差数据。
    盘存汇总报表
        查看盘存汇总报表数据。

预警管理
    食材过期预警
        查看食材过期预警数据，处理预警。
    日采购价格预警
        查看日采购价格预警数据，处理预警。
    月采购价格预警
        查看月采购价格预警数据，处理预警。

共治监管
    日管控
        查看日管控数据，提交日管控。
    周排查
        查看周排查数据，提交周排查。
    月调度
        查看月调度数据，处理月调度。

公告
    查看公告数据。
```
